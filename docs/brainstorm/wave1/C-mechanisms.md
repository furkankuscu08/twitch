## Gaps and null results (stated so they are not mistaken for absence)
- **Chinese live commerce** (red envelopes, lucky bags, countdowns): no mechanism-level success evidence found. Only a correlational study (1,472 Douyin sessions, Jan-Mar 2023): interactivity raises fan growth, partly via retention. Journal page was inaccessible (403), so this is [S]. Generic keyword-comment draws are a standard tool (Shopline help page [S]).
- **Kick:** searches returned vendor comparisons (revenue split, looser rules), no distinct interaction mechanism.
- **Discord Activities/Stages:** no per-Activity usage found. Only "apps used by over 25% of MAU" (search snippet from Discord's blog; page failed with a certificate error) and a SDK opening in March 2024. Stages: nothing found.
- **TikTok official data** on interactive games: none. All evidence for rows 3 and 11 is third-party.
- **Instagram Live:** nothing current. **Esports/sports second screen:** no engagement numbers for X-Ray, Pick'Em.

## Assumptions checked
- **"Affiliate-only features unavailable to us":** supported for Power-ups [V] and Polls [V, 2022]; Predictions disputed [U]; chat, raid, and chat-message EventSub documented without an Affiliate mention, but the docs page was truncated so this is unconfirmed [U].
- **Evidence against building a row-1/4/7 clone:** each had a spike-then-decay or regulatory pattern (rows 4, 7, 9), and the strongest success claims are author-reported or vendor-reported.
