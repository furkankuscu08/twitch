**@Xemdo** (Marc Szanto, Twitch Developer Relations), 23 Oct 2026, answering whether the app must “use Codex” or only be built with it: “The rules listed within the hackathon provides more in-depth information on what is required during submission, including information in regards to the usage of Codex.” ([post](https://x.com/Xemdo/status/2113761978183508232), link resolves to the Devpost page below).

The page those posts point at, [twitchcon-codex.devpost.com](https://twitchcon-codex.devpost.com), says judges want original ideas and names these as starting points, “not templates”:

- Streamer collaboration: streamers talk, play, or create together
- Audience participation: Twitch Plays, live polls, streamer distractions
- Content enhancements: tabletop dice roller, live sports overlay, IRL or science-stream tools

Requirement stated there: the project “connects to Twitch (e.g. Twitch API, EventSub, chat, Extensions, overlays) and was built with OpenAI Codex.” Submission asks for a repo, a public YouTube demo (max 3 minutes) showing it working on Twitch and how Codex was used, a description, and a Codex session ID. Judging criteria, quoted from that page: Innovation/Idea (“does the project differ from existing concepts?”), Potential Impact (“useful or entertaining… for streamers and their communities”), Technological implementation (“how well does it use Codex?”), Design (“easy to use and fun to watch?”). Prizes: $10,000 / $6,000 / $4,000 / $2,500 / $2,500, each with stage time. Deadline on the page: **2 Nov 2026, 2:00pm PST**.

A @Build3DAO roundup says the same hackathon “closes Nov 3” ([post](https://x.com/Build3DAO/status/2114326493811945679)). The Devpost page and the @devpost post both say 2 Nov, 2:00pm PT.
